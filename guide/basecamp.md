That is the best way to learn, but it has limits: sessions reset and your files disappear, you cannot easily run a script on a schedule, big datasets do not fit, and you cannot rebuild exactly the same setup next year. Your own computer fixes all of those, and it needs a little setup, once.</p><p>Most beginner pain is not about Python at all. It is about <em>which</em> Python is running, and where. So we fix that first, once, properly.</p><h3>Terminal first aid</h3><p>The <strong>terminal</strong> is a window where you type commands instead of clicking. It looks unfriendly but it only does what you tell it, and it never breaks anything you did not ask it to. Open it now: <strong>Terminal</strong> on macOS (press <kbd>Cmd</kbd>+<kbd>Space</kbd>, type Terminal), <strong>PowerShell</strong> on Windows (Start menu, type PowerShell). Each line you type ends with <kbd>Enter</kbd>.</p><p>A terminal is always "standing" in one folder, called the <strong>working directory</strong>. These five commands cover 90 percent of what you will ever need:</p><div class="q-table-wrap"><table class="q-table"><thead><tr><th>Command</th><th>What it does</th></tr></thead><tbody><tr><td><code>pwd</code></td><td>Print where you are standing now (on Windows PowerShell: also <code>pwd</code>).</td></tr><tr><td><code>ls</code></td><td>List what is in this folder (Windows PowerShell understands <code>ls</code> too).</td></tr><tr><td><code>cd folder_name</code></td><td>Step into a folder. <code>cd ..</code> steps back out to the parent folder.</td></tr><tr><td><code>mkdir new_folder</code></td><td>Make a new folder.</td></tr><tr><td><code>python script.py</code></td><td>Run a Python file (once Python is installed, below).</td></tr></tbody></table></div><ul><li>Press <kbd>Tab</kbd> after typing the first letters of a name and the terminal completes it. It saves typing and typos.</li><li>Press <kbd>&uarr;</kbd> to bring back the previous command. Press <kbd>Ctrl</kbd>+<kbd>C</kbd> to stop something that is running.</li><li>Copy a command, right-click or <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>V</kbd> to paste, then Enter. A command that prints nothing usually worked.</li><li>An error message is not a disaster: read the last line, exactly as in Stage 2.</li></ul><p>Do the <strong>terminal drill</strong> in the practice section at the end of this stage before you start the install steps.</p><h3>1. Install VS Code</h3><p>Download it from <a href="https://code.visualstudio.com/" target="_blank" rel="noopener">code.visualstudio.com</a> and run the installer. VS Code is a text editor that grows into an IDE when you add extensions. It will be where you write scripts, run notebooks, browse files, and use a terminal, all in one window.</p><aside class="q-callout is-tip"><strong class="q-callout-title">macOS only: enable the <code>code</code> command</strong><p>Open VS Code, press <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>, type <code>Shell Command: Install 'code' command in PATH</code> and press Enter. Windows and Linux installers usually do this for you.</p></aside><h3>2. It is what lets VS Code find your data, scripts and environment.</p><h3>5. Add extensions</h3><p>An <strong>extension</strong> is an add-on that teaches VS Code new skills. You install them from inside VS Code, and you will use the same few clicks every time you want a new one.</p><ol><li>Click the <strong>Extensions</strong> icon in the vertical bar on the far left of the window. It looks like four squares with one flying off. No icon bar? Use the menu: <strong>View</strong>, then <strong>Extensions</strong>. Keyboard shortcut: <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (Windows, Linux) or <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> (Mac).</li><li>Click the search box at the top of the panel. It says <em>Search Extensions in Marketplace</em>. The Marketplace is VS Code's app store, and everything in it is free to install.</li><li>Type the name from the table below, for example <code>Python</code>. Results appear underneath, most popular first.</li><li>Pick the right result: check the <strong>publisher name</strong> under the title, and the download count (the good ones have millions or hundreds of thousands). Click the result to read its description on the right.</li><li>Click the blue <strong>Install</strong> button. Wait a few seconds until it changes to a gear icon. That means it worked. If a <strong>Reload</strong> or <strong>Restart Extensions</strong> button appears, click it.</li><li>Repeat for each extension in the table.</li></ol><div class="q-table-wrap"><table class="q-table"><thead><tr><th>Search for</th><th>Publisher</th><th>What it does for you</th></tr></thead><tbody><tr><td><strong>Python</strong></td><td>Microsoft</td><td>Runs and debugs <code>.py</code> files, finds your conda environments, adds autocomplete.</td></tr><tr><td><strong>Jupyter</strong></td><td>Microsoft</td><td>Opens <code>.ipynb</code> notebooks inside VS Code and runs cells.</td></tr><tr><td><strong>Rainbow CSV</strong></td><td>mechatroner</td><td>Colours each column of a CSV differently so you can read raw data files.</td></tr><tr><td><strong>Data Wrangler</strong></td><td>Microsoft</td><td>Opens a DataFrame as a scrollable grid with summary stats.</td></tr><tr><td><strong>Error Lens</strong></td><td>Alexander (usernamehw)</td><td>Prints errors and warnings at the end of the offending line. Great for making errors feel normal.</td></tr></tbody></table></div><aside class="q-callout is-tip"><strong class="q-callout-title">Find an exact extension with its ID</strong><p>Every extension has a unique ID. Typing it with <code>@id:</code> in front shows exactly one result, so you cannot pick a look-alike. Try <code>@id:ms-python.python</code>. The IDs for this guide are <code>ms-python.python</code>, <code>ms-toolsai.jupyter</code>, <code>mechatroner.rainbow-csv</code>, <code>ms-toolsai.datawrangler</code> and <code>usernamehw.errorlens</code>.</p></aside><aside class="q-callout is-trap"><strong class="q-callout-title">Look-alikes</strong><p>Searching <code>Python</code> returns many extensions. Choose the one published by <strong>Microsoft</strong> with the blue verified checkmark next to the publisher name and the largest download count. Installing the Python extension also adds a few helpers (such as Pylance) automatically. That is normal.</p></aside><p>To confirm everything is installed, type <code>@installed</code> in the search box. You should see all five in the list. The same box shows other useful filters: <code>@recommended</code> for suggestions, and the clock icon for recently updated extensions.</p><h3>6.
