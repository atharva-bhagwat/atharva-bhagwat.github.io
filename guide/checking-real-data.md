The habit that separates careful analysts from unlucky ones is a <strong>data audit</strong>: a short, systematic look at the table before you draw any conclusions.</p><h3>What this dataset is about</h3><p><strong>PTEN</strong> is a human protein that acts as a brake on cell growth signalling. When it is damaged the brake weakens, and changes in the PTEN gene are linked to several cancers and inherited conditions. Geneticists keep finding single-letter changes in the gene. Many swap one amino acid in the protein for another (a <strong>missense</strong> variant), and for most of them nobody knows whether the change matters.</p><p>A <strong>multiplexed assay of variant effect</strong> attacks this by making thousands of variants at once and measuring each one. This table comes from an experiment that measured <strong>abundance</strong>: how much of each PTEN variant ends up in the cell. Each variant is tagged with a fluorescent marker and put into cells. The cells are sorted into four bins from dim to bright and sequenced, so every variant gets a count of reads per bin. That is the same shape as the toy table in Stage 3, only with about four thousand variants. A change that makes the protein unstable is cleared away by the cell, so its cells look dim.</p><aside class="q-callout is-why"><strong class="q-callout-title">Abundance is not activity, and activity is not disease</strong><p>A variant can be plentiful but not working, or scarce and still partly working. Abundance tells you which changes destabilise the protein, which is one useful clue when judging whether a variant is harmful. It is not the final answer.</p></aside><h3>Two scores, one idea</h3><p>Both the toy table and this table have a column called <code>score</code>, but they are <strong>not the same measurement</strong>.</p><div class="q-table-wrap"><table class="q-table"><thead><tr><th></th><th>Toy table (Stage 4)</th><th>PTEN table (this stage)</th></tr></thead><tbody><tr><td>How it was made</td><td>You calculated it: a weighted average of the four bins.</td><td>Published by the researchers, from their own analysis.</td></tr><tr><td>Typical range</td><td>1 to 4. Higher means brighter cells.</td><td>About 0 to 1. It has been rescaled.</td></tr><tr><td>Reference points</td><td>None. 4 means every read was in the brightest bin.</td><td>The unchanged protein is set to 1. Broken, cut-short proteins sit near 0.</td></tr></tbody></table></div><p>Both turn "where along the dim-to-bright scale do this variant's cells land?" into one number.
