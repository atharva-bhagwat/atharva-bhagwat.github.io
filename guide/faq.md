<section class="q-plan"><p class="q-lede">Short answers to the questions people ask first.</p><details class="q-faq" open><summary>Do I have to do everything?</summary><p>No. Nothing is required. The stars exist so you can see where you have been, not to grade you. Take the stages that help you and skip the rest.</p></details><details class="q-faq" open><summary>I have never written code. Where do I start?</summary><p>Start with the <a href="/articles/intro-to-python-biosci">warm-up</a> (about 10 minutes), then follow the plan from the top: Project 0, Notebook Ridge, Traceback Gorge, and so on. Do one stage at a time. Each is small, and you can stop whenever you like.</p></details><details class="q-faq" open><summary>How long does it take?</summary><p>The warm-up takes about 10 minutes. Each stage after that is roughly 30 to 60 minutes, and there is no deadline. The stages marked Core add up to about 7 hours, spread over as many days as you like. Part 2 and the optional stages are extra.</p></details><details class="q-faq" open><summary>I know a little Python. Where should I jump in?</summary><p>Every notebook sets itself up, so you can start at any stage. Pick the row that describes you:</p><div class="q-table-wrap"><table class="q-table"><thead><tr><th>If...</th><th>Start at</th></tr></thead><tbody><tr><td>You have never coded</td><td><a href="/articles/intro-to-python-biosci">Warm-up, then Project 0</a></td></tr><tr><td>You know variables, loops and a bit of Python, but not pandas</td><td><a href="/articles/intro-to-python-biosci/table-flats">Table Flats</a></td></tr><tr><td>You know basic pandas and want real data</td><td><a href="/articles/intro-to-python-biosci/audit-pass">Audit Pass</a></td></tr><tr><td>You only want plotting</td><td><a href="/articles/intro-to-python-biosci/histogram-meadow">Histogram Meadow</a></td></tr><tr><td>You want to practise writing conclusions from data</td><td><a href="/articles/intro-to-python-biosci/the-summit">The Summit</a></td></tr><tr><td>You want to set up your own computer</td><td><a href="/articles/intro-to-python-biosci/basecamp">Basecamp</a></td></tr><tr><td>You want to run things on the cluster</td><td><a href="/articles/intro-to-python-biosci/hpc">the HPC page</a></td></tr></tbody></table></div><p>If a stage feels too hard, go back one. If it feels too easy, skip ahead.</p></details><details class="q-faq" open><summary>Do I need to install anything?</summary><p>Not for Part 1. Everything runs in Google Colab in your browser, and you need only a free Google account. Part 2 is where you set up Python on your own computer, and it is optional.</p></details><details class="q-faq" open><summary>What are the stars? Are they saved?</summary><p>Each stage ends with a puzzle: run your code, type the answer you get, and a star lights up. A few ask you to explain what a result means in your own words. Your stars are saved in this web browser only, on this computer. Clearing your browser data or switching devices starts you from zero, but your notebooks are safe in your own Google Drive.</p></details><details class="q-faq" open><summary>Does Colab save my work?</summary><p>Only if you choose <strong>File, Save a copy in Drive</strong> when you open a notebook. Without that, your edits are lost when the session ends. Files you create inside a session also disappear when it ends.</p></details><details class="q-faq" open><summary>I am stuck. What do I do?</summary><p>Read the last line of the error message first: it usually says what is wrong. <a href="/articles/intro-to-python-biosci/traceback-gorge">Traceback Gorge</a> shows how. Every exercise has a hidden solution you can open when you have tried for a while, and every puzzle has a nudge.</p></details><details class="q-faq" open><summary>Do I need to know biology?</summary><p>No. Each column and word is explained when it first appears, and <a href="/articles/intro-to-python-biosci/audit-pass">Audit Pass</a> gives a short background on the dataset.</p></details><details class="q-faq" open><summary>Can I use my own computer instead of Colab?</summary><p>Yes. Download a notebook from Colab (File, Download, .ipynb) and open it in VS Code or Jupyter. <a href="/articles/intro-to-python-biosci/basecamp">Basecamp</a> shows how to set that up.</p></details><details class="q-faq" open><summary>How do I reset my stars?</summary><p>Use the Reset stars link at the top of any page. It clears everything on this browser.</p></details><p class="q-colab-row"><a class="q-colab" href="/articles/intro-to-python-biosci/plan">Back to the plan</a></p></section>
