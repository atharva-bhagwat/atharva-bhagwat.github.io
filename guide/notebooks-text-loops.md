It is made of <strong>cells</strong>. A code cell holds Python and shows its result underneath. A text cell holds notes, headings and reminders for yourself.</p><aside class="q-callout is-tip"><strong class="q-callout-title">Keyboard shortcuts worth learning today</strong><ul><li><kbd>Shift</kbd>+<kbd>Enter</kbd>: run the cell and move to the next one (Colab and VS Code).</li><li>Colab: <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>M</kbd> then <kbd>B</kbd> adds a cell below, then <kbd>D</kbd> deletes a cell.</li><li>In both, the <strong>+ Code</strong> and <strong>+ Text</strong> buttons add cells.</li></ul></aside><h3>The kernel has a memory</h3><p>Behind every notebook runs a <strong>kernel</strong>: a Python program that does the work. When you run a cell, the kernel runs it and <strong>remembers</strong> the variables you created. The notebook shows the code; the kernel holds the values. They can disagree. Try it with two cells:</p><div class="qcode"><div class="qcode-bar"><span class="qcode-name">cell 1</span><button class="qcopy" type="button">Copy</button></div><pre><code><span class="n">x</span> <span class="o">=</span> <span class="mi">10</span></code></pre></div><div class="qcode"><div class="qcode-bar"><span class="qcode-name">cell 2</span><button class="qcopy" type="button">Copy</button></div><pre><code><span class="nb">print</span><span class="p">(</span><span class="n">x</span> <span class="o">*</span> <span class="mi">2</span><span class="p">)</span></code></pre></div><p>Run both and you get <code>20</code>. Now change cell 1 to <code>x = 100</code> but <strong>do not run it</strong>, and run cell 2 again. Still <code>20</code>: the page says 100, but the kernel still remembers 10.</p><h3>When things go wrong with memory</h3><div class="q-table-wrap"><table class="q-table"><thead><tr><th>What you see</th><th>Why it happens</th><th>What to do</th></tr></thead><tbody><tr><td>An old value shows up after you edited a cell</td><td>You changed the code but did not run it again.</td><td>Run the cell, and the cells below it.</td></tr><tr><td><code>NameError: name 'df' is not defined</code></td><td>The cell that creates it has not run in this session (new session, restart, or you skipped it).</td><td>Run the cells above it, or <strong>Run all</strong>.</td></tr><tr><td>A number grows every time you run a cell</td><td>Cells like <code>count = count + 1</code> add again each run.</td><td>Run the cell that sets <code>count = 0</code> first, or restart.</td></tr><tr><td>Results that do not match your code</td><td>You ran cells in a different order than they appear.</td><td><strong>Restart and run all</strong>.</td></tr><tr><td>Colab says it ran out of memory, or the session crashed</td><td>The data was too big for the free machine, or the session was idle too long.</td><td>Restart the session. Work on a smaller piece of the data first.</td></tr></tbody></table></div><aside class="q-callout is-why"><strong class="q-callout-title">Restart, then run everything</strong><p>A notebook is only trustworthy if it works from the top, in order, in a fresh kernel. Before you believe a result or share a notebook, restart and run all. In Colab: <strong>Runtime, Restart session and run all</strong>. In VS Code: the <strong>Restart</strong> button, then <strong>Run All</strong>.</p><ul><li><strong>Restart</strong> clears the kernel's memory (all variables). Your code and notes stay.</li><li>Colab also forgets everything when a session ends: variables, and any files you uploaded. Save your notebook to Drive.</li><li>You do not need to clear memory often. Restart when results look wrong, after big edits near the top, or when the notebook feels stuck.</li></ul></aside><h3>Text</h3><p>Text in Python is called a <strong>string</strong>. A <strong>slice</strong> <code>text[start:stop]</code> takes letters from <code>start</code> up to, but not including, <code>stop</code>. Counting starts at 0, and negative numbers count from the end.</p><div class="qcode"><div class="qcode-bar"><span class="qcode-name">run this</span><button class="qcopy" type="button">Copy</button></div><pre><code><span class="n">name</span> <span class="o">=</span> <span class="s2">"p.Trp18Ter"</span>
