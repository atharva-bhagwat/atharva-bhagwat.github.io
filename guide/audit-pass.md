Real data arrives with quirks, so the habit that separates careful analysts from unlucky ones is a <strong>data audit</strong>: a short, boring, systematic look at the table before any conclusions.</p><h3>What this dataset is about</h3><p><strong>PTEN</strong> is a human protein that acts as a brake on cell growth signalling. It is an enzyme (a phosphatase) that removes a phosphate group from a signalling lipid, which dampens a pathway that tells cells to grow. When PTEN is damaged, the brake weakens, and changes in the PTEN gene are linked to several cancers and to inherited conditions. Geneticists keep finding single-letter changes in the gene. Many swap one amino acid in the protein for another (a <strong>missense</strong> variant), and for most of them nobody knows whether the change matters.</p><p>A <strong>multiplexed assay of variant effect</strong> attacks that gap by making thousands of variants at once and measuring each one. This table comes from an experiment that measured <strong>abundance</strong>: how much of each PTEN variant ends up in the cell. Each variant is tagged with a fluorescent marker and put into cells. Cells are then sorted into four bins from dim to bright and sequenced, so each variant gets a count of reads per bin. That is exactly the shape of the toy table from Stage 3, only with about four thousand variants. A change that makes the protein unstable gets cleared away by the cell, so its cells look dim and its reads pile up in the low bins.</p><aside class="q-callout is-why"><strong class="q-callout-title">Abundance is not activity, and activity is not disease</strong><p>A variant can be abundant but inactive, or scarce and still partly working. Abundance data tells you which changes destabilise the protein, which is one useful ingredient when judging whether a variant is harmful. It does not tell you the final answer.</p></aside><h3>Two scores, one idea</h3><p>Be careful: the toy table and this table both have a column called <code>score</code>, but they are <strong>not the same measurement</strong>.</p><div class="q-table-wrap"><table class="q-table"><thead><tr><th></th><th>Toy table (Stage 4)</th><th>PTEN table (this stage)</th></tr></thead><tbody><tr><td>How it was made</td><td>You computed it: a weighted average of the four bins, weights 1 to 4.</td><td>Published by the researchers, from their own analysis of the sorted-cell data.</td></tr><tr><td>Typical range</td><td>1 to 4.
